# vibe-hnindex Docs

Documentation site for [vibe-hnindex](https://github.com/AndyAnh174/vibe-hnindex) — a local MCP server for codebase indexing and search.

**Live:** [docs.hnindex.cloud](https://docs.hnindex.cloud)

## Stack

- Next.js 16 + Turbopack
- shadcn/ui v4 + Tailwind CSS v4
- next-intl (EN/VI)
- next-themes (dark mode)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to `main` — Vercel auto-deploys from `docs-site/` directory.
