# hnindex-cli

Installs [vibe-hnindex](https://www.npmjs.com/package/vibe-hnindex) MCP config for Claude Code, Claude Desktop, Cursor, Antigravity, Windsurf, and VS Code (`hnindex init --mcp …`).

**Repository:** [github.com/AndyAnh174/vibe-hnindex](https://github.com/AndyAnh174/vibe-hnindex) (monorepo path `packages/hnindex-cli`).

**Docs:** [Getting started → CLI](https://github.com/AndyAnh174/vibe-hnindex/blob/main/docs/getting-started.md#cli-installer-hnindex)
